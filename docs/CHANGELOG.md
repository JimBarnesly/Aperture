# Changelog

## 1.0.0~rc1 — 29 October 2026

- Visible product renamed **Aperture**. Existing `apeture` Kodi IDs and ZIP roots
  retained for settings/upgrade compatibility; see [RENAME.md](RENAME.md).
- Native Kodi 21/Omega candidate: original misty-bridge Home, populated-system
  Games/RetroPlayer, native album shelf and full pinned Estuary foundation.
- Unified release-candidate metadata and exact install-kit filenames.
- Content-verified materialization: `--skip-vendor` rejects stale inputs and
  modified assembled files. SHA-256 provenance and deterministic ZIP packaging.
- Updated scope, installation and evidence docs; historical desktop Music/GUI
  checks separated from exact-RC checks and remaining Pi hardware acceptance.
- Hermes, Home Assistant and streaming receivers deferred. No stable-release or
  hardware-compatibility claim until the acceptance checklist is completed.
