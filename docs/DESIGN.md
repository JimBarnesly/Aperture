# Scenic Home experiment

## Intention

An atmospheric living-room media centre, informed by the quiet full-screen scenery
and horizontal navigation of older XBMC skins. The user remembered a stone bridge
in mist; **the exact old skin and image have not been identified**. This is a fresh
Apeture design, not a claim to reproduce a particular Behance project or Aeon asset.

The scene takes precedence over interface decoration. There are no marketing
slogans, oversized controller illustrations, pretend library counts, sample films
or fabricated album covers. Navigable destinations stay readable at TV distance.

## Layout and interaction

- Authored at 1920 × 1080, 16:9. Other resolutions use Kodi scaling, to be verified
  on the user's actual display; no claim of a separately authored ultrawide layout.
- Original bridge scene fills the screen. A separate translucent scrim improves
  header/footer readability without altering the source image.
- Small Apeture mark at upper left; Kodi time and date at upper right.
- Games, Movies, TV, Music, Files and Settings occupy a continuous lower-third
  charcoal-glass band. Focus is white type, a mild cyan tint and a thin cyan rule.
- Left/right wrap through IDs `9100`–`9105`. Up reaches the corresponding visible
  section action `9300`–`9305`; Back or any direction there returns to its section.
- Down from a main destination reaches Power (`9200`). The utility row wraps
  Power, Favourites and Playback controls. Up/Down/Back return to explicit visible
  main destinations: Games from Power, TV from Favourites, Music from Playback.
  There is no asynchronous data fetch or library population required for focus.
- Select opens real Kodi windows. Movies/TV/Music distinguish populated versus
  empty libraries. Games without the companion opens the installation explanation;
  it never silently downloads, enables or installs a game client.
- Kodi's inherited window Back behavior, full settings and skin-switch confirmation
  remain intact. The optional native Format-inspired album shelf is described in
  `MUSIC_SHELF.md`; receiver/streaming work remains deferred.

The complete pinned Estuary window foundation is intentionally retained. This
experiment customizes Home, named fonts, the default palette, and existing source
overrides; it does not claim a newly designed player, library or every modal.

## Preview and verification contract

```sh
python tools/vendor_estuary.py --output build/skin.apeture
python tools/vendor_estuary_assets.py --output build/skin.apeture \
  --preview build/apeture-scenic-games-preview.png
python tools/vendor_estuary_assets.py --output build/skin.apeture \
  --preview build/apeture-scenic-music-preview.png --selection music
python tools/vendor_estuary_assets.py --output build/skin.apeture \
  --preview build/apeture-scenic-music-action-preview.png --selection music --focus-action
python -m unittest discover -s tests -v
python tools/validate.py
```

Previews read actual Home XML, generated textures, the committed scene and bundled
font outlines. Nine-slice button borders and the selected section's real empty-state
conditions are evaluated. The clock/date in a preview are illustrative. Every export
has a permanent **DESIGN PREVIEW — not a Kodi runtime screenshot** label. The preview
cannot verify Kodi focus transitions, animation, remote controls, overscan or playback.
The font hinting workaround applies only to in-memory preview copies; distributed
font files are unchanged. Runtime validation is still required before a release is
called working on the Pi. See `TESTING.md` for the device checklist.
